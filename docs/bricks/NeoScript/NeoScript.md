## Стратегии импорта (`ImportStrategy`)

Источник: `catroid/src/main/java/org/catrobat/catroid/neoscript/NeoScriptImporter.java:48-53`. Сигнатура дубликата — `scriptSignature`: имя класса скрипта + отпечаток содержимого; для триггерных скриптов в сигнатуру входит ключ триггера (сообщение, фон, кнопка геймпада, bucket/path Firebase, пин/фронт Raspi, ID пользовательского блока, имя цели, условие) (`NeoScriptImporter.java:176-231`).

| Стратегия | Поведение (`importScripts`, `NeoScriptImporter.java:67-174`) |
|-----------|--------------------------------------------------------------|
| `SKIP_DUPLICATES` | Скрипты, чья сигнатура уже есть у целевого объекта, пропускаются (`result.skipped`), остальные добавляются. Эквивалент `overwrite=false` (`NeoScriptImporter.java:61-65`). |
| `REPLACE_DUPLICATES` | Скрипты цели, чьи сигнатуры входят в импортируемый набор, удаляются, затем добавляются все импортированные (клонированные + релинк переменных); добавленные с непустой сигнатурой фиксируются в `result.replaced`. Эквивалент `overwrite=true` (`NeoScriptImporter.java:109-144`). |
| `APPEND_ALL` | Все импортированные скрипты добавляются безусловно, без проверки дубликатов (`NeoScriptImporter.java:160-162`). |
| `REPLACE_ALL` | Все скрипты целевого объекта очищаются (`getScriptList().clear()`), затем добавляются импортированные; клоны подготавливаются ДО очистки (`NeoScriptImporter.java:81-99`). |
